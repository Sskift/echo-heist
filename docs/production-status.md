# 制作状态 / v0.18.0

当前方向：手工设计的潜入解谜主线，重视精妙配合与人物叙事。

0.17 精修旧馆与车站的代表场景：旧馆采用木地板镶边、城市旧影、失物展柜与怀表；车站采用石材分区、登记牌、时钟、FAST / SERVICE 识别色与相向的柜面。装饰沿用现有建筑和实体掩体位置，地面图案不改变路线。

玩家以围巾与背包识别，普通守卫使用制服帽和徽记，追踪器使用面罩、硬壳背包与天线；回声保留玩家轮廓及自己的编号颜色。交互动作读取操作记录，实际凭据在当前持有者手中或柜槽中显示。守卫停住时切回待机；回声删除后的模型按颜色编号匹配。
