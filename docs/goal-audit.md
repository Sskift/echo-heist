## 系统与叙事

已经有固定 60Hz 模拟、三回声、精确位置回放、终点待命、重录、撤销、快进、局部计划存档、安全锚点、预演与失败定位。时序窗口、扫描、电源、唯一凭据和抑制的基础规则已实现。C2 增加玻璃、稳定调查分配、抵达后搜索与返回、公开安保状态，声响链的前后依赖有反例检查。

v0.12.0 完成计划要求的失败交互时间标记：操作轨道与列表按实际结算记录时间、操作者、目标与原因，包含抑制漏播和留候取消；未来请求与十二秒截断单独显示。点击暂停、键盘阅读、手机布局、重试清空、预演隔离与相同录像在不同配合下得到不同结果均有验证。这只补齐解题反馈，不证明谜题直观性或真实主线时长达标。

C3 已实现供电分流、灯光视距、摄像头、取物与撤离的供电条件，以及已预告的取物后断电与恢复。C7 已实现实体植入、独立回执与最终归还，回声不能代替真人交付。继续保持规则确定、意图冲突可解释、回声不复制实物、投影碰撞规则一致。

C4 已实现终端时段、远端开关、前置授权与供电条件；标明留候的终端支持单次请求等待送件，离开或被抑制取消，竞争不复制凭据。地图与面板公开条件和持有者。多棒接力必须按真实持有权录下交付，实体货单只由真人取走；车站取物后需恢复出口。旧普通终端的单帧请求行为保留。

C5 已实现周期与重叠抑制、回声继续移动但暂时失效、保留唯一凭据、错过操作不补放和重新登记留候。投影追踪器忽略真人，只追可见回声与最后可见位置；声响调查优先，断电清除线索。规则、倒计时与目标在地图和面板公开。实际路线还验证缺少诱饵、错误延迟或取件后错误恢复顺序会失败。

C6 已实现成功时提交电路结果，公开两态后果，按前序选择加载实际不同的设施与布局；刷新保留，回退清除后续结果，分支录像隔离。每个任务至少两种完整方案，章末入口、调度与交接的八种组合都经过引擎和浏览器验证。取件封路需要备用路线与延后复位，三处少回声路线有短暂可测警觉，双回声路线可保持零警觉。八个替代布局不增加主线行动区数量。内容工具穷举可达选择与刷新恢复；实际首次玩家是否理解后果、选择是否有趣仍待验证。

C7 前三个任务将目标反转为实体送达。真人携带证据，在已签名、有人值守、供电和提交窗口满足时按 E 植入；提交后封路需要延后复位。守卫必须到场搜索发现副本，再实际返回登记点才形成回执。先确认值班员回执再切换线路，由延迟诱饵引导监察员，两份独立回执缺一不可。机制边界、实际路径、浏览器输入和逐段存档已验证。

C7 后三个任务将送件、签名、诱导与留守在三条回声间轮换，已分别验证去掉任一角色会破坏参考解；当前恢复的线路同时决定下一间的人工或签名接应。五段终局先进入核心、恢复公共身份、公开责任证据，再决定私人档案范围并完成独立交付。公开完整档案要求两份登记回执；归还私人记忆要求当事人授权和提交后恢复民用核验。两种结局各自真实完成，刷新可重读；回退只清除最后两段本轮结果，历史结局保留，手机与键盘交互已覆盖。

已实现完整剧情链：公共记录缺失 → 身份交易 → B-17 转运到市政档案库 → 封存系统与民用电网共用设备 → 取出核心并恢复城市供电 → 找回 B-17 主动留下的授权链和货运票 → 带出抹除批准书与新坐标，发现联络员的签名 → 核验搭档仍以临时身份藏在旧渡口 → 取得独立证据 → 带出责任清单和中央总库地址 → 植入证据并取得独立回执 → 恢复公共身份索引，找回沈舟的名字 → 公开包括联络员责任在内的证据 → 决定私人记忆的公开或归还 → 关掉投影器，在旧渡口现实重逢。剧情明确：回声记录动作，被交易的是私人档案片段，被抹除的是公共索引；恢复身份不会自动补回失去的生活。两种收束各有代价，均保留已公开的责任证据。

作者工具有拆分的章节数据、设施检查、参考输入、替代解与可达分支组合检查；全部 132 个必经行动区另有逐锚点保存、重载的实际引擎通关。可视化地图编辑界面尚无。C1–C7 使用三层提示；输入容错、可读性、低视力与不同经验玩家的理解需在真人测试中继续检查。
