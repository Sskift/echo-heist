# 制作状态 / v0.16.0

当前方向：手工设计的潜入解谜主线，重视精妙配合与人物叙事。

本文记录已实现并通过本地验证的内容。当前开发顺序统一见 [下一步制作计划](next-steps.md)。用户新增的美术要求优先：以真实 3D 场景和固定等距镜头制作 2.5D 游戏。早期长期计划与逐关预算已移除。

八章 48 个任务、130 个必经行动区已可玩，14 个后果分支布局，4 个机制样例和 3 个基础演习。合计 52 任务、134 个规范行动区、148 个实际布局。主线有身份恢复、责任证据交付、私人档案范围选择与旧渡口重逢。家具、人物与动画采用 Kenney CC0 模型，三首离线配乐按场景切换。

0.16 将游戏场景换为 Three.js 实时 3D 渲染。建筑墙面、窗框、门禁、地板和灯光为项目代码建模；档案柜、桌子、壁灯、书本、植物、收音机与人物使用有许可的模型。角色播放 Idle / Run 骨骼动画，回声使用同一骨架的透明着色；摄像头仍是独立设备。关卡实体与视野检测继续使用原始模拟坐标。

全景适合规划，跟随近景适合观察人物与机关；手机近景额外放大，标签按实际显示宽度缩放。前景墙切低，遮挡玩家的邻近墙自动降低。WASD、方向键与触屏输入按画面方向旋转回世界坐标，旧录像无需迁移。原先的平面人物精灵与 Canvas 场景渲染器已退役。

0.16 同时完成 C4-6《不存在的列车票》的三段凭据接力。首区将唯一车票交进 FAST 或 SERVICE，第二段由本人从柜子对侧接回并签入，第三段将原票交给回声完成最后授权与归还，本人带走实体货单。前段安排会改变后两区所需岗位数。

交接位置、必要签名与本人接回记录随成功锚点保存；重试恢复入站状态，预演不能提交，回退清除下游交接与计划。旧 C4 四区存档保留历史通关和后续解锁。`?demo=station-transfer` 使用独立任务与计划键，不写入主线存档。

本地验证：25 个单元检查、8 个浏览器流程、52 任务 / 148 布局的统一内容验证与生产构建通过。桌面和手机实际截图已检查。新版美术是首轮可玩基线，尚需继续细化逐章空间、角色辨识与镜头表现；不据自动路线宣称真人体验已经验证。

0.15 将 C3-6 改为《最后一盏灯》三段连续任务。玩家选择货梯或提前解锁检修口，留下原始回声录像在配电室工作；后段实际读取其开关状态，三个名额中持续占用一个。核心拆离切断货梯与民用线路，最后返回同一房间重接 CIV。街区灯窗与电车铃响应真实恢复动作。

连续任务支持只读预演、本区失败重试、留守录像与本区计划分别保存、原路回退及下游计划失效。旧四区版本的历史通关与后续解锁保留，新布局从首段重新准备。`?demo=last-light` 是独立试玩入口，使用独立存档，不写主线进度与故事选择。

新增机制由 2 个状态测试和 1 个浏览器流程覆盖，0.15 当时总量为 22 个单元测试、6 个浏览器流程。两条完整路线与其存档恢复在统一内容验证器执行，未新增另一套章节通关测试。

0.14 把故事从关卡旁的单句说明扩展为 20 段章节与关键事件演出。修表铺贯穿调查：怀表、车票、文件、收音机和两只杯子作为视觉与情节线索。玩家可续读、跳过、回顾已解锁故事与证据。两处对话回答影响后续台词和尾声，不能代替关卡中真正执行的行动选择。
