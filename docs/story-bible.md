# 回声劫案 · 叙事编排

## 叙事约束

视角固定为正在潜入的人。玩家记得搭档，问题在于公共机构拒绝承认他的身份；不能把“登记被抹除”写成主角脑中失忆。回声只是动作记录，无法思考、复活或复制实体物件。记忆交易涉及私人的档案片段。恢复身份索引不会补回失去的岁月。

开场的目标是找回搭档，调查中逐渐承认其他受害者的存在，最后将责任追查与私人生活的处置分开。公开责任证据是两个结局的共同前提；公开全部档案会造成隐私伤害，归还私人封套仍须保持罪证可核验。搭档在 C6 联络时表达自己的意愿，最终选择不能把这句请求藏起来。

## 人物与物件

**你**：修表铺的使用者，也是会用回声设备的窃贼。擅长安排具体动作，面对失踪先追个人线索，再主动承担行动对城市和他人的影响。不用额外身世反转解释所有行为。

**搭档 / 沈舟**：最初通过怀表、值守协议和预留授权留下痕迹；C6 由暗号、独立记录与旧授权链证实仍活着，以临时身份藏在旧渡口；C7 恢复公共登记的姓名，尾声真正重逢。他主动留下通道并表达记忆边界，具有自己的行动与意愿。

**联络员**：起初熟悉目录、安保和转运线路，C1 对目录的反应埋下疑点；C5 原件揭露其批准抹除，C6 使用独立来源核验责任。协助取证不消除其责任，两条对话回应均不提供“赦免”选项。

**修表铺**：章间反复返回的生活地点。两只杯子从等待到倒扣，再到听见搭档声音后重新摆正；怀表的两道划痕来自曾经等待彼此的约定；车票指向他为后来的人留下的路。原创 SVG 保持与地图一致的低饱和绿、纸张和黄铜色，五种物件随段落聚焦。只用已有离线配乐，无外部运行请求。

## 八章节奏

| 章节 | 开场 / 核心问题 | 关键事件与离场 |
| --- | --- | --- |
| C0 序章 | 空椅子、清空失物柜的期限；动作回声帮你进入需要两个人的门 | C0-2 发现怀表；C0-6 身份编号仍有效，转向私人拍卖 |
| C1 错峰作案 | 按认证时刻表进入宴会 | C1-3 目录第一次明确贩卖私人生活、埋下联络员疑点；C1-6 账本通向市政档案库 |
| C2 替保安排班 | 观察值夜人员，不把所有人都写成幕后反派 | C2-6 电网图揭示安保与民生共线，下一步行动有现实代价 |
| C3 停电之夜 | 把民用恢复写进行动计划 | C3-6《最后一盏灯》：留同伙供电、隔窗取核心、回同一间配电室重接民用线；灯亮后回答为何绕路，后文回收动机 |
| C4 把现在交给过去 | 唯一凭据需要真实交接；搭档预留接收席位 | C4-4 用往事解释等待协议；C4-6 货运票是给追来者的通道 |
| C5 专门抓鬼的人 | 回声动作在抑制场内失效，先观察同伙何时还能配合 | C5-6 原件上的签名；面对联络员，定下继续合作的条件 |
| C6 自己写作案计划 | 由玩家自己选入口，联络员提供可核对的后果 | C6-2 真实通话与热茶承诺；C6-6 责任清单完整，准备把证据送出去 |
| C7 最后一个自己 | 从取走证据转为植入、见证与独立回执 | C7-3 责任证据进入多方记录；最终任务恢复身份、公开责任、决定私人范围，再到旧渡口 |

20 段场景的正文与挂接点以 `src/story.ts` 为准。每章有开场，C0–C6 有章末收束，C0-2、C1-3、C4-4、C6-2、C7-3 有关键事件段落。最后一章使用现有的双分支交付与完整尾声，不再插入另一套结局。

## 回答与后果

- C3-6：「不能让邻居替我付账」或「带回能让人相信的证据」。影响 C6 出发前的准备与自述。
- C5-6：「继续帮忙，签名也要公开」或「给坐标，逐条核对」。影响 C6 联络员对话与最终出发去渡口前的调查交接。
- 没有回答时使用中性叙述。点击回答先保存草稿，完成本段才提交；跳过不提交草稿，回看不能改写已提交回答。
- 对话不发放道具、不自动完成任务、不选择结局。关卡内入口、电路和交付范围保持实际操作结果。

## 存档与呈现

独立故事键 `echo-heist-story-v1` 保存已读、回答和未读完的位置，不改动旧任务与回声计划格式。收起与 Esc 保留页码；刷新或修表铺可续读。阅读、回顾时停止游戏计时，关闭后由玩家恢复行动。

场景根据任务可用性或历史完成记录解锁；证据只在整项任务完成后归档。旧存档只自动补入当前章开场或当前任务的事后段落，其余已解锁内容留供自选。任务板隐藏未解锁任务的标题与简介，避免把人物和结局提前泄露。

剧情不自动滚屏、不打字机限速；所有按钮可用键盘，焦点进入标题，关闭后返回原控件。手机采用上图下文布局，内容可滚动，不把选择放在横向溢出区域。
