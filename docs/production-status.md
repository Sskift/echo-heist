# 制作进度 / v0.12.1

八章故事已经可以从头通关并抵达两种结局，当前作为试玩版交付。十小时时长与首次体验仍未验收；预算和自动通关都不能证明首次玩家的实际时长。

正式主线共 48 个任务、132 个行动区，完成一章后可直接进入下一章。C0 章末取原件时可由两人分别留守，或先借临时 A 录下换岗路线、删除临时录像，最后只用一条回声先守 A 再去 B；沿用精确位置回放，不修改已发布地图。C1 章末回执室可用一条往返回声走上方通道，也可用两条留守回声走下方检修通道。C2 章末最后可用回声开下门或零回声等待上方时序门。C3 章末先完成核心拆离与民用主线恢复，最后一段可使用回声压力门或零回声检修窗口接入备用馈线。C4 章末前三段接通终端、连续交接、取走货单并恢复出口；末段可凭据接力，也可先本人持票进入、录下内侧人工放行，再让下一轮走检修门。C5 章末拆开感知与抑制网络，取件后按顺序保护留守者，最后可让两条回声诱导追踪器，或只留一名同伙、由真人先切断追踪供电再释放它。C0–C5 的替代方案均已分别通过引擎验证。

C6 每个任务均有至少两种原理不同的完整方案。入口改变后续设施；取证顺序交换两间的布局与帮助关系；供电留下签名终端与监控，或暗处巡逻与开放通道。后半章把上方留守或下方签名备用线用于取件封路，安排回声在断电以后复位；三处证人取证区分别支持少回声与零暴露方案。章末四段连续选择入口、安保调度与交接方式，八种组合均可带出责任清单与传输地址，并恢复 CIV。C6 的八个与 C7 的两个额外分支布局均不重复计入必经体量。

C7 后半章要求送件者交付后值守、签名者授权后换岗、诱饵发声后返回支援；三段中的凭据分别由第三条回声、真人、第一条回声保管。线路选择改变下一间的人工接应或签名接力，提交复位民用与见证供电后必须恢复。五段终局先恢复公共身份、公开责任证据，再选择私人档案公开或归还；两种交付都以实际送达收束。旧渡口与沈舟重逢，回声技术、记忆交易与身份抹除的边界在剧情中明确说明。

已制作任务的设计预算合计 750 分钟，**没有真人实测结果**。这不代表当前版本已经达到十小时或有对应时长的有效内容。

模拟次序：更新开关 → 移动与声响 → 分派调查 → 记录 E 请求 → 结算电源请求 → 按最新抑制状态结算交付、接收、授权 → 更新门禁 → 守卫与扫描感知 → 真人植入及一次性后果、发现与回执 → 真人取物及一次性后果 → 更新受影响门禁 → 核对撤离条件与时限。实体目标的后果覆盖这一帧更早的电源请求；影响安保时从下一帧感知。电源对声响的影响从下一模拟帧开始。同帧相反电源请求不改变状态。

## 验证与局限

v0.12.1 用单点时序扰动发现并修正 C5-3-c / C5-6-b 的录制顺序与提示：先录 A，再录 Q 控制，最后录 B，取消真人与回声重复拨动同一开关的要求。录控制时尚无 B 回声，恢复 Q 不会迫使玩家抢按保存。两关均覆盖 ±0.5 秒切换偏差和保存前一秒停留，并通过真实键盘通关、刷新恢复。地图、引擎结算和旧录像格式不变。新增 `check:timing` 用于排查主要与替代参考路线的敏感点，不能代替真人容错与体验测试。

同轮检查发现 C3-2-b 的参考停机时间贴着报警边缘，延后两帧就失败。现将停机从约 3.2 秒提前到约 3 秒，保留约 6.1 秒的回程恢复；±0.1 秒单点偏差与真实键盘北进南出已验证。没有放宽摄像头、门、时限或判定。对较大单点偏差敏感的其他路线仍在检查报告中显示，供首玩时观察；不能把通过此检查写成所有路线均已达到发布质量。

修订后完整时序检查覆盖 142 个主线布局（132 个必经区及 10 个额外布局）、163 条主要或替代参考路线，共 3,544 次单点扰动。一两帧敏感项为 0；仍有 29 个动作对更大扰动敏感并保留在报告中。此数量不含机制试验、基础演习或真人数据，只表示当前这组参考输入在指定探针下的结果。

v0.12.0 补齐失败交互的时间点与原因。12 项引擎检查覆盖电源结算前后抑制差异、同帧冲突、终点不重复 E、留候登记与取消、迟到凭据、授权条件、实体植入和报警、日志与录像隔离。5 项浏览器流程覆盖原请求在真人送件后成功、抑制漏播经延迟恢复、点击与键盘暂停阅读、手机布局、超时提示与刷新、真人植入与回声仅录请求。此改动不调整谜题、结算顺序或存档格式；首次玩家能否借助这些反馈理解配合，仍需外部测试。

所有 136 个主线与机制试验行动区、146 个含分支的布局均有真实引擎下通过八方向输入完成的参考解，C0–C5 章末替代解单独回放；另有一次从 C0 到 C7、逐锚点保存与重载的完整 132 区回归。原有三关也有实际路线回归。浏览器覆盖真实键盘通关、延迟避扫、回执撤离、玻璃诱导、双声源分配、零回声撤离、电路录像、照明视距、核心拆离与民用恢复、提示分层、存档、重录、预演、空手接收、时段接力、留候与远端授权、连续签名、车站两条末段路线、抑制脉冲与真人接管、追踪器预演、失效时持有凭据、恢复时重新接收、审计员末段两解、移动端布局和试玩导出。

C2 还验证去掉声响后的关键路线会失败，以及第一声确实会改变第二声的响应守卫。空间索引加速墙体碰撞与视野查询，对照原始几何算法验证非网格墙体、边界、玻璃和动态门。

C3 验证每条参考路线去掉电路操作后无法完成、只开门而不停共线监控会暴露，以及真实核心路线按“取物前供电 → 取物断电 → 后续恢复 → 成功”推进。独立单元用例还验证没有实体门时也不能绕过撤离条件，同帧提前恢复会被随后拆离覆盖，重试回到原供电，预演与重录不触发实体后果。

C4 验证窗口首尾帧、同帧交付接收、竞争取消、等候不重复发出请求、离开与抑制取消、存档重建与预演隔离。参考输入还检查空手录制失败而回放成功、远端无人时授权失败、漏掉前置签名无法完成，以及货单取出后监控启动、恢复 P 才能撤离。两种章末路线分别让真人接到凭据、或让回声保留凭据并操作内侧电源，交接记录不同。

C5 验证周期首尾帧、相位和重叠，追踪器不识别真人、只记最后可见位置、视线遮挡与玻璃差异、目标排序、声音覆盖和断电清除。实际路线验证缺少延迟或诱饵会失败，抑制中凭据不会丢，留候取消后必须重新请求，三回声分时控制能完成，以及取件后先恢复同伙再关追踪会失败。章末两种方案分别保留追踪供电并诱导调查、或关闭追踪供电，全程真实输入。

C6 验证完整分支、逐锚点刷新、回退重选、缺失选择修复、错误布局拒绝提交、预演与重录隔离。后半章检查取件确实关闭入口、提前复位会被取件覆盖、延后复位才能回程，以及三处少回声方案都有短暂警觉、双回声方案警觉峰值为零。章末八种选择组合在引擎与浏览器中逐段完成；去掉延迟、诱饵、抑制复位或 CIV 恢复都会破坏相关参考方案。三次选择回退时只保留上游结果。内容校验器还穷举可达选择前缀，要求每种结果都有实际参考输入，检查每个锚点能恢复。

时长记录按共同阶段编号归档，另存实际分支与选择事件，避免把两个替代布局计作两个必经阶段。上述反例和警觉峰值只核验对应的作者方案，不代表已经穷尽所有玩家可能发现的解法。

C7 前三任务已有七段参考输入与浏览器真实按键通关。验证植入条件的时段首尾、长按失败不补交、同帧先授权后提交、提交覆盖此前供电、后果只发生一次、报警当帧不提交、录像保存与重录/预演隔离、巡逻路过不算发现、停止供电时不能登记，以及重试清除回执。分时诱饵配合值班线路切换分别引导两名守卫；少一份回执不能完成。遗漏诱饵或未恢复见证人回程的门禁都会破坏相关参考方案。植入与回执面板可暂停阅读，地图标明目标、携带副本与登记位置，手机布局已检查。测试时钟消除了浮点边界丢帧，游戏仍使用原有固定 60 Hz 模拟。

C7 后三任务和两个额外布局均有浏览器实际输入通关。两种最终选择从第一段开始完整执行，最终交付后才能打开尾声；刷新、Esc 关闭、手机滚动、回退重选和历史结局都已覆盖。三回声角色轮换分别去掉任一岗位会破坏对应参考解；忽略民用恢复或独立见证也无法完成相关路线。C0 章末的单回声换岗有整场验证，删掉临时助手后的计划刷新仍可用；不给真人留足穿 A 门的时间，换岗方案会失败。

自动参考解证明可完成，不证明首次玩家理解、谜题质量或游玩时长。真人测试尚未开展。时长审查命令会检查完整内容、全体开测名单、导出哈希和人工复核；目前必经内容缺口为零，但合格真人记录为零，验收仍失败。[试玩协议](playtesting.md) 说明统计口径和外部核对要求。

M0 的四种机制已有可玩样例，仍需玩家判断直观性与趣味性。八章内容与剧情结局已有可玩初稿；作者工具仍是数据定义与命令行验证，没有拖放编辑器。外部首玩质量、十小时时长、十二份特别契约、组合任务、回放分享与玩家编辑器未完成。完整目标逐项见 [目标审查](goal-audit.md)。
