## 系统与叙事

已经有固定 60Hz 模拟、三回声、精确位置回放、终点待命、重录、撤销、快进、局部计划存档、安全锚点、预演与失败定位。时序窗口、扫描、电源、唯一凭据和抑制的基础规则已实现。C2 增加玻璃、稳定调查分配、抵达后搜索与返回、公开安保状态，声响链的前后依赖有反例检查。

C3 已实现供电分流、灯光视距、摄像头、取物与撤离的供电条件，以及已预告的取物后断电与恢复。尚缺后续章节的完整机制组合、跨阶段可选择结果及其回退、最终植入或归还目标。必须继续保持规则确定、意图冲突可解释、回声不复制实物、没有突然改变投影碰撞规则。

C4 已实现终端时段、远端开关、前置授权与供电条件；标明留候的终端支持单次请求等待送件，离开或被抑制取消，竞争不复制凭据。地图与面板公开条件和持有者。多棒接力必须按真实持有权录下交付，实体货单只由真人取走；车站取物后需恢复出口。旧普通终端的单帧请求行为保留。

已实现序章至车站的剧情链：公共记录缺失 → 身份交易 → B-17 转运到市政档案库 → 封存系统与民用电网共用设备 → 取出核心并恢复城市供电 → 找回 B-17 主动留下的授权链和货运票，追查防投影临时转存区。此时搭档的现况仍未知。重逢、技术真相和最终公开全部档案 / 公开罪证并归还私人记忆的选择尚未进入可玩内容，不能算故事已经闭合。

作者工具有拆分的章节数据、设施检查、参考输入和替代解；可视化地图编辑界面尚无。C1–C4 使用三层提示；后续章节仍需逐段制作适合观察与推理的提示。输入容错、可读性、低视力与不同经验玩家的理解需在真人测试中继续检查。
