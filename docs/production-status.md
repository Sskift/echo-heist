# 制作进度 / v0.3.0

这是长期计划的首批可玩实现。完整八章与十小时主线仍在制作，不能把内容预算视为当前版本时长。

## 当前可玩内容

- 序章六个任务、十个手工行动区，按任务逐步解锁。
- 最后一场「旧馆最后一班」包含潜入、取证、撤离三段，每段独立规划与保存。
- 四个独立机制样例：延迟出场、电路、信息接力、回声抑制。
- 原有三个关卡保留为「基础演习」，旧回声存档可继续使用。
- 主线通讯、阶段结果和六条证据构成寻找失踪搭档的序章；本版收束到下一章拍卖会的线索。

合计新增 14 个可玩行动区，加上原有 3 个演习。只有序章的 10 区属于正式主线初稿，机制试验不计主线时长。

## 已实现的系统

| 系统 | 行为与边界 |
| --- | --- |
| 任务与锚点 | 成功才提交；刷新恢复下一阶段；阶段回退移除之后的本轮事实，保留历史任务解锁；回声按行动区保存 |
| 延迟出场 | 0–6 秒，每格 0.25 秒；出场前没有感知或交互效果；末尾截断可见；支持撤销与重录 |
| 设备操作 | E 记录明确的电源状态或凭据请求；回放时检查实体 ID、距离和当下条件 |
| 唯一凭据 | 一个持有者；终端交付先于接收；同帧竞争接收取消，凭据留在终端；授权需要持有凭据 |
| 抑制场 | 投影继续走，暂时不能操作、压开关或制造声响；保留凭据所有权；恢复后不补放已错过的事件 |
| 只读预演 | 克隆当前已提交计划，0–12 秒查看；不包含真人，不提交进度、不改正式计划；暴露时停在失败处 |
| 失败诊断 | 标明第几秒、哪个自己被哪个守卫看见，画面圈出位置 |
| 安保 | 巡逻者调查声响；固定哨兵忽略诱饵；调查目标被障碍隔开时按网格寻找路线 |
| 作者检查 | 独立任务数据、八方向输入参考解、实体与前置事实校验；普通地图不需要改引擎 |

模拟次序：更新开关 → 移动与声响 → 记录 E 请求 → 结算电源请求 → 按最新抑制状态结算交付、接收、授权 → 更新门禁 → 安保感知 → 目标与时限。电源对声响的影响从下一个模拟帧开始。冲突电源请求不改变状态；同类相同状态请求可合并。

## 验证与局限

每个新增行动区都有通过真实引擎、八方向移动与操作完成的参考解。浏览器另覆盖序章解锁、跨阶段刷新与回退、延迟存档、预演隔离、电源回放，以及信息接力的完整键盘通关。

自动参考解证明可完成，不证明首次玩家理解、谜题质量或游玩时长。尚未进行外部盲测，不能宣称序章已有 45 分钟，也不能宣称已满足十小时主线。

M0 的四种机制已有可玩样例，仍需玩家验证是否直观、有趣。M1 的序章内容和系统已形成可玩初稿；当前作者工具为数据定义与命令行检查，尚无拖放式地图编辑器。C1–C7、十二份特别契约、组合任务、回放分享和玩家编辑器尚未制作。
