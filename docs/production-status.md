正式主线共 18 个任务、43 个行动区，完成一章后可直接进入下一章。C1 章末回执室可用一条往返回声走上方通道，也可用两条留守回声走下方检修通道。C2 章末同样有四段，最后可用一条回声调度并开下门，也可零回声等待上方时序门。两章的替代方案均已分别通过引擎验证。

C0–C2 的设计预算合计 225 分钟，**没有真人实测结果**。这不代表当前版本已经有对应时长的有效内容。

## 已实现的系统

| 系统 | 行为与边界 |
| --- | --- |
| 任务与锚点 | 成功才提交；刷新恢复下一阶段；回退移除之后的本轮事实，保留历史任务解锁；回声按行动区保存 |
| 延迟出场 | 0–6 秒、0.25 秒步长；数字输入或加减；编辑暂停；末尾截断可见；支持撤销与重录 |
| 时序门禁 | 多开关同时成立、任一成立、恰好一人或全部离岗；可组合响应窗口和多次开门 |
| 周期扫描 | 公开范围、周期、倒计时；连续暴露 0.3 秒失败；可在只读预演检查 |
| 设备操作 | E 记录明确电源状态或凭据请求；回放检查实体 ID、距离和当下条件 |
| 唯一凭据 | 一个持有者；交付先于接收；同帧竞争取消；授权需要持有凭据 |
| 抑制场 | 投影继续走，暂时失去交互与感知效果；保留凭据；恢复后不补放事件 |
| 只读预演 | 克隆已提交计划，检查 0–12 秒；不含真人、不保存进度；暴露时停在失败处 |
| 失败诊断 | 指出第几秒、哪个自己、哪名守卫或扫描器，圈出位置 |
| 安保 | C2 最近可响应者接手调查，同帧确定性配对；抵达后搜索再绕障碍返回；旧图保留共同响应；固定哨兵忽略诱饵 |
| 玻璃与公开规则 | 玻璃挡身体不遮视线；地图显示守卫编号、调查目标与参考响点；安保面板显示响应规则、视听范围及搜索状态 |
| 提示与剧情 | C1、C2 三层提示、章节折叠目录、阶段通讯、跨章推进、已获证据 |
| 作者检查 | 设施引用、前置事实、八方向参考解、替代解；地图与引擎分开 |
| 试玩记录 | 自愿启用，仅本机；实际墙钟、阶段、提示、失败、离开与导出；自动化标识不能用于真人验收 |

模拟次序：更新开关 → 移动与声响 → 分派调查 → 记录 E 请求 → 结算电源请求 → 按最新抑制状态结算交付、接收、授权 → 更新门禁 → 守卫与扫描感知 → 目标与时限。电源对声响的影响从下一模拟帧开始。同帧相反电源请求不改变状态。

## 验证与局限

所有 47 个主线与机制试验行动区均有真实引擎下通过八方向输入完成的参考解，C1、C2 章末替代解单独回放。原有三关也有实际路线回归。浏览器覆盖真实键盘通关、延迟避扫、回执撤离、玻璃诱导、双声源分配、零回声撤离、提示分层、存档、重录、预演、接力、移动端布局和试玩导出。

C2 还验证去掉声响后的关键路线会失败，以及第一声确实会改变第二声的响应守卫。空间索引加速墙体碰撞与视野查询，对照原始几何算法验证非网格墙体、边界、玻璃和动态门。

自动参考解证明可完成，不证明首次玩家理解、谜题质量或游玩时长。真人测试尚未开展。时长审查命令会检查完整内容、全体开测名单、导出哈希和人工复核；缺 C3–C7 或缺真人数据时明确失败。[试玩协议](playtesting.md) 说明统计口径和外部核对要求。

M0 的四种机制已有可玩样例，仍需玩家判断直观性与趣味性。前三章已经可玩；作者工具仍是数据定义与命令行验证，没有拖放编辑器。完整八章、剧情结局、十二份特别契约、组合任务、回放分享与玩家编辑器未完成。完整目标逐项见 [目标审查](goal-audit.md)。
